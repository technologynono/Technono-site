# Gravity Defying Science

A modern landing page exploring the fascinating intersection of maglev technology, theoretical physics, and the future of interstellar travel.

## 🚀 Features

- **Modern UI:** Built with React 19 and Tailwind CSS for a sleek, dark-themed aesthetic.
- **Responsive Design:** Optimized for various screen sizes.
- **Interactive Elements:** Features core research area cards and a multimedia player preview.
- **Rich Iconography:** Uses Lucide React for consistent and beautiful icons.

## 🛠️ Tech Stack

- **Frontend Framework:** [React](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/technologynono/Technono-site.git
   cd Technono-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:5173`.

### Production Build

Create a production-ready build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
